# POTOQUITOS — Google Stitch Export

Coloca aquí el archivo ZIP o los archivos exportados desde tu proyecto de Google Stitch:
https://stitch.withgoogle.com/projects/593871137804037120?pli=1

En Stitch:
1. Abre el proyecto en Microsoft Edge.
2. Abre el menú superior (icono de tres líneas `≡` o menú del proyecto).
3. Selecciona "Download Project" (o "Descargar proyecto" / exportar código).
4. Guarda o descomprime el contenido en esta carpeta (`stitch_export/`).
